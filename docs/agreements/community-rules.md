# 无名树社区规范

> 版本：v1.0（2026-11-11 起生效）
> 说明：本文件是产品内「社区规范」页面的正本（客户端页面内容与本文件保持一致）。

## 一、三条基本原则

不排名、不打卡、不比孩子。这里不比较进度、不比较恢复快慢、不比较孩子的表现。请以陪伴与经验分享为目的发言。

## 二、树洞怎么用

1. 树洞是「楼」，不是聊天流：一帖一楼，按楼层回应，请围绕帖子内容交流。
2. 发帖默认匿名，显示为「一位家长」。
3. 回应不是义务，没有人必须回复；也没有「已读」统计，请放心慢慢说。
4. 涉及孩子时请使用化名或不具名描述，避免可识别信息。

## 三、禁止行为

1. 广告、代购、刷单、募捐、校外拉群、导流到其他平台或私下联系方式（如「加微信」「加 QQ」）。
2. 晒娃攀比、炫耀成绩、排名比较，或对其他家庭成员的评判。
3. 人身攻击、辱骂、恐吓其他成员。
4. 医疗诊断、用药建议或「保证能好」的承诺；分享就诊经验请以个人经历为限。
5. 发布其他成员或孩子的隐私信息。
6. 以社群名义从事任何牟利活动。

## 四、内容审核与处理

内容发布前经过机器审核，可疑内容会进入管理员人工复核后再展示。违规内容可能被拒绝发布或移除；多次违规或严重违规的账号可能被暂停或移出社群。

## 五、危机时刻

如果你或孩子正处在自伤、自杀等紧急风险中，请立即联系专业机构或当地紧急救援（如 120、心理援助热线）。社群伙伴无法替代专业支持，管理员看到相关求助信息会尽力提醒你联系专业帮助，但不会因此移除你的帖子——在树下说出来是被允许的。

## 六、举报与申诉

看到违反规范的内容，可在帖子内举报，管理员会尽快处理。对你本人内容的处理有异议时，也可通过「我的」页联系管理员申诉。
